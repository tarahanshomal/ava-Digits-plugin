# آوا برای دیجیتس

افزونهٔ مستقل **ava-Digits-plugin** برای ارسال رمز یک‌بارمصرف دیجیتس از طریق سرویس پیامک آوا، توسعه‌یافته توسط [طراحان شمال](https://github.com/tarahanshomal).

- افزودن درگاه آوا به فهرست درگاه‌های پیامکی Digits.
- ارسال با الگوی تأییدشدهٔ OTP آوا و نگهداری صفر ابتدای کد.
- تنظیمات فارسی و پشتیبانی از شماره‌های ایرانی و ارقام فارسی/عربی.
- اتصال HTTPS با کلید API حساب شما و شناسهٔ یکتای درخواست.
- نگهداری کلید در تنظیمات آوا، بدون نمایش مجدد آن در فرم.

این افزونه اتصال آوا را فراهم می‌کند؛ افزونهٔ اصلی و دارای مجوز **Digits** باید جداگانه نصب و فعال باشد. ساخت کد، بررسی کد، انقضا، محدودیت ارسال و فرایند ورود و ثبت‌نام بر عهدهٔ Digits است. این مخزن شامل نسخهٔ Digits نیست.

## نصب و تنظیم

1. از [Releases](https://github.com/tarahanshomal/ava-Digits-plugin/releases/latest) فایل **ava-Digits-plugin-1.0.0.zip** را دریافت کنید. برای نصب از ZIP پیوست انتشار استفاده کنید.
2. در وردپرس به **افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه** بروید، ZIP را نصب و فعال کنید.
3. در پنل آوا یک **الگوی پیامک رمز یک‌بارمصرف** حاوی `{code}` بسازید و تأیید آن را دریافت کنید. شناسهٔ همان الگو را بردارید.
4. کلید API با مجوز **`sms_otp:send`** بسازید. این مجوز با مجوز پیامک متنی `sms:send` و OTP صوتی `otp:send` متفاوت است.
5. در **تنظیمات ← آوا برای دیجیتس** نشانی پنل، کلید API و شناسهٔ الگو را وارد و اتصال را فعال کنید. نشانی پیش‌فرض **`https://ava.tarpardaz.com`** است؛ پنل اختصاصی باید HTTPS داشته باشد.
6. در **Digits ← SMS Gateway** درگاه **آوا / Ava SMS OTP** را انتخاب کنید. فیلد «اتصال آوا» را روی «استفاده از تنظیمات ← آوا برای دیجیتس» بگذارید و متن الگوی پیام در دیجیتس را دقیقاً **`{OTP}`** قرار دهید. تنظیمات را ذخیره کنید.

دیجیتس کد را جایگزین `{OTP}` می‌کند و این افزونه همان کد را به API الگوی آوا می‌فرستد. متن نهایی پیامک را **الگوی تأییدشده در آوا** تعیین می‌کند. بنابراین نام فروشگاه، متن خوشامد و توضیحات را در الگوی آوا تنظیم کنید، نه کنار `{OTP}` در دیجیتس. کد باید ۴ تا ۸ رقم باشد.

ارسال پس از نصب غیرفعال است. پیش از فعال‌سازی در سایت اصلی، تنظیمات و ورود را در محیط آزمایشی بررسی کنید. آزمایش ارسال در Digits پیامک واقعی و هزینه‌دار می‌فرستد.

## کلید API

کلید ذخیره‌شده در فرم نمایش داده نمی‌شود. برای حفظ کلید قبلی فیلد را خالی بگذارید؛ برای جایگزینی، کلید تازه را وارد کنید. کلید را در گیت، گزارش خطا یا تصویر منتشر نکنید. امکان تعریف کلید در `wp-config.php` نیز وجود دارد:

```php
define( 'AVA_DIGITS_API_KEY', 'YOUR_AVA_API_KEY' );
```

مقدار نمونه را با کلید حساب خود جایگزین و ثابت را پیش از پایان تنظیمات وردپرس تعریف کنید. محدودیت IP کلید را، در صورت استفاده، مطابق IP خروجی هاست وردپرس تنظیم کنید.

فیلد برند اختیاری است. آن را خالی بگذارید تا برند تأییدشدهٔ الگو استفاده شود؛ مقدار واردشده باید دقیقاً با برند الگو یکسان باشد.

## نتیجهٔ ارسال و حریم خصوصی

پذیرش درخواست توسط آوا به معنی تحویل پیامک به گوشی نیست. وضعیت نهایی را در گزارش پنل آوا بررسی کنید. افزونه هنگام قطع ارتباط یا نتیجهٔ نامشخص، خودکار ارسال را تکرار نمی‌کند. ارسال مجدد آگاهانه در Digits نیز تابع محدودیت‌ها و هزینهٔ سرویس است.

درخواست یکسان در همان اجرای PHP دوباره فرستاده نمی‌شود. هر بار «ارسال مجدد» در Digits درخواست تازه‌ای است و می‌تواند هزینهٔ تازه ایجاد کند.

هنگام ارسال، شمارهٔ گیرنده، کد یک‌بارمصرف، شناسهٔ الگو، پارامترهای انتخاب‌شده و کلید احراز هویت از طریق HTTPS به پنل آوای تنظیم‌شده فرستاده می‌شوند. افزونه گزارش محلی شامل کد و متن پیام نمی‌سازد. پایگاه داده، بکاپ و افزونه‌های گزارش‌گیری HTTP سایت را طبق سیاست خود مدیریت کنید. اطلاعات سرویس در [پنل آوا](https://ava.tarpardaz.com) در دسترس است.

## توسعه و ساخت بسته

```sh
php tests/run.php
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 scripts/package.py
```

بستهٔ قابل نصب و SHA256 در پوشهٔ `build/` ساخته می‌شوند. بسته‌بندی از فهرست مجاز فایل‌ها استفاده می‌کند و فایل‌های توسعه را وارد ZIP نمی‌کند. گردش CI نحو و آزمون‌ها را روی PHP 7.4، 8.2 و 8.4 بررسی می‌کند. گردش انتشار، ZIP و checksum را برای تگ هماهنگ `vX.Y.Z` به GitHub Releases اضافه می‌کند.

قرارداد اتصال از افزونهٔ منتشرشده توسط نویسندهٔ [Akay Digits در WordPress.org](https://plugins.svn.wordpress.org/akay-digits/trunk/akay-digits.php) بررسی شده است: فیلترهای `digits_sms_gateways` و `unitedover_send_sms`. راهنمای اصلی سازندهٔ Digits برای [تنظیم درگاه‌ها](https://help.unitedover.com/digits/kb/how-to-setup-custom-gateway/) نیز در دسترس است. نسخه‌های تجاری یا بومی‌شده ممکن است رفتار متفاوت داشته باشند؛ پیش از استفادهٔ اصلی، نصب خود را بررسی کنید.

### اعتبارسنجی نسخهٔ ۱٫۰٫۰

این نسخه **۱۳۴ بررسی رفتاری PHP** و **۳ آزمون بسته‌بندی** را گذرانده است. همچنین **۴۵ بررسی روی وردپرس واقعی 7.1.4** با PHP 8.5.4 و افزونهٔ رسمی SQLite Integration 3.1.3 انجام شد: فعال‌سازی، حذف، تنظیمات، مجوز مدیریت، nonce، پنهان‌ماندن کلید، اجرای فیلتر درگاه، حفظ صفر کد و پاسخ‌های خطا. تمام درخواست‌های پیامک شبیه‌سازی و ارتباط بیرونی و ایمیل بسته شدند.

بستهٔ تجاری Digits در محیط آزمون موجود نبود؛ ورودی فیلترهای آن طبق قرارداد منتشرشده شبیه‌سازی شد. بنابراین این نتایج، تأیید آزمون کامل ورود با نسخهٔ نصب‌شدهٔ Digits شما یا تحویل واقعی پیامک نیستند.

## English

Ava SMS OTP gateway for Digits by Tarahan Shomal. Install Digits separately, configure your HTTPS Ava panel URL, an API key with `sms_otp:send` and an approved SMS OTP template, then select Ava in Digits and set its message template to exactly `{OTP}`. Ava renders the approved template; Digits generates and verifies codes. Iranian mobile numbers and 4–8 digit codes are supported. API acceptance is not delivery confirmation. No real SMS is sent by automated tests.
