# دیجیتس آوا — پیامک و رمز صوتی

نسخهٔ **۱٫۲٫۰** اتصال آوا، توسعه‌یافته توسط [طراحان شمال](https://github.com/tarahanshomal)، با تنظیمات مستقیم داخل Digits و بستهٔ کامل قابل نصب.

- رمز یک‌بارمصرف **پیامکی استاندارد** با نام سایت، دامنه و کد؛ شناسهٔ قالب را خالی بگذارید.
- رمز یک‌بارمصرف **صوتی** از طریق تماس و خواندن کد.
- الگوی پیامکی اختصاصی و پیامک متنی با خط فرستندهٔ مجاز.
- تنظیمات آوا داخل صفحهٔ درگاه پیامک دیجیتس؛ حفظ تنظیمات نسخهٔ قبلی.
- استفاده از کد اصلی دیجیتس با حفظ صفر ابتدایی و رفع تداخل درگاه نسخهٔ IPPanel.
- ارتباط HTTPS، شناسهٔ یکتای ارسال، محافظت تنظیمات و آزمون ارسال با nonce.

راهنمای کامل نصب و راه‌اندازی: **[آموزش فارسی اتصال آوا به دیجیتس](docs/SETUP-FA.md)**.

## پیامک استاندارد با نام و دامنهٔ سایت

در نسخهٔ **۱٫۲٫۰**، روش «الگوی رمز پیامکی» با شناسهٔ قالب خالی، نام سایت و دامنهٔ عمومی وردپرس را همراه کد اصلی به آوا می‌فرستد. آوا این متن ثابت سه‌خطی را می‌سازد:

```text
نام سایت - {NAME}
دامنه - {DOMAIN}
کد تایید - {OTP}
```

`{NAME}` عنوان سایت در **تنظیمات ← عمومی** و `{DOMAIN}` فقط نام میزبان نشانی سایت است؛ مسیر، درگاه، query و اطلاعات ورود URL ارسال نمی‌شوند. عنوان سایت برای ارسال از HTML پاک و یک‌خطی می‌شود و حداکثر ۶۰ نویسه دارد. عنوان و دامنه باید نام عمومی معتبر سایت باشند؛ شمارهٔ تماس، URL یا متن تبلیغاتی را در عنوان قرار ندهید. متن آزاد دیجیتس جای متن استاندارد را نمی‌گیرد.

این مسیر برای همهٔ حساب‌های فعال، دارای مجوز سرویس و اعتبار کافی، **۲۴ساعته و بدون تأیید جداگانهٔ هر رمز یا قالب سیستمی** در دسترس است. فاصلهٔ ارسال مجدد، محدودیت نرخ، سقف حساب و انقضای OTP حفظ می‌شوند. برای اضافه‌شدن نام و دامنهٔ سایت، اتصال را به ۱٫۲٫۰ به‌روزرسانی کنید؛ روش‌های قالب اختصاصی، متنی و صوتی تنظیمات فعلی خود را حفظ می‌کنند.

## صدای فارسی طبیعی؛ بدون نصب مجدد

صدای فارسی طبیعی جدید در سرویس مرکزی آوا اعمال شده است. برای دریافت این صدای جدید، نسخهٔ ۱٫۱٫۱ نیز به نصب مجدد یا به‌روزرسانی نیاز ندارد. نسخهٔ ۱٫۲٫۰ قابلیت نام و دامنهٔ پیامک استاندارد را اضافه می‌کند. برای تماس، روش **رمز صوتی با تماس آوا** را انتخاب و ذخیره کنید.

## کدام فایل را نصب کنم؟

از **[صفحهٔ دانلود افزونه‌های آوا](https://ava.tarpardaz.com/plugins)** یا [آخرین انتشار گیت‌هاب](https://github.com/tarahanshomal/ava-Digits-plugin/releases/latest) دریافت کنید:

| فایل | کاربرد |
| --- | --- |
| **ava-Digits-full-8.6.2-1.2.0.zip** | بستهٔ کامل Digits 8.6.2 به همراه اتصال آوا؛ شامل تنظیمات فرم ورود، ثبت‌نام، ظاهر و ووکامرس |
| **ava-Digits-plugin-1.2.0.zip** | فقط اتصال آوا، برای سایتی که Digits را از قبل نصب دارد |

برای هر فایل، checksum با پسوند `.sha256` نیز موجود است. فایل خودکار «Source code» بستهٔ نصب نیست.

بستهٔ کامل از نسخهٔ مرجع IPPanel ارائه‌شده ساخته می‌شود؛ مرجع با SHA256 ثابت کنترل می‌شود و درگاه اختصاصی آن با آوا جایگزین می‌شود. سورس اختصاصی آوا، اسکریپت ساخت و منشأ وابستگی‌ها در همین مخزن هستند. [مشخصات اجزای دیگر](THIRD-PARTY-NOTICES.md).

## نصب بستهٔ کامل

1. از وردپرس و پایگاه دادهٔ خود نسخهٔ پشتیبان بگیرید. اگر افزونهٔ جداگانهٔ «Ava Digits» فعال است، آن را غیرفعال کنید.
2. فایل **ava-Digits-full-8.6.2-1.2.0.zip** را از **افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه** نصب کنید. برای جایگزینی Digits موجود، گزینهٔ جایگزینی نسخه را بررسی و انتخاب کنید. اطلاعات کاربران و تنظیمات Digits توسط بسته‌ساز آوا حذف نمی‌شوند.
3. افزونهٔ Digits آوا را فعال و از منوی **Digits → Authentication → SMS Gateway** وارد تنظیمات شوید. مسیر مستقیم، پس از آدرس وردپرس شما:

```text
/wp-admin/admin.php?page=digits_settings&tab=apisettings
```

بستهٔ کامل همهٔ بخش‌های بومی دیجیتس را نگه می‌دارد. آوا تنظیمات اتصال، روش ارسال و API را در بخش درگاه اضافه می‌کند. کدهای اصلی ورود، ثبت‌نام و فعال‌سازی Digits توسط بسته‌ساز تغییر نمی‌کنند.

## تنظیم اتصال

در [پنل آوا ← اتصال و کلیدهای API](https://ava.tarpardaz.com/panel#developers) کلید بسازید. برای استفاده از هر دو روش OTP پیامکی و صوتی، مجوزهای **`sms_otp:send`** و **`otp:send`** را روی همان کلید انتخاب کنید.

در وردپرس، درگاه **آوا / Ava OTP (پیامکی و صوتی)** را انتخاب کنید. در بخش «اتصال درگاه آوا»، گزینهٔ **ارسال آوا** را روشن کنید، نشانی پنل، کلید API و روش ارسال را وارد و با دکمهٔ **ذخیرهٔ تنظیمات آوا** ثبت کنید. این دکمه، درگاه انتخاب‌شدهٔ آوا و روش ارسال را هم ذخیره می‌کند؛ پس از نمایش پیام موفقیت، با بازکردن دوبارهٔ صفحه، روش انتخاب‌شده را بررسی کنید.

**نشانی پنل:** `https://ava.tarpardaz.com`؛ برای پنل نمایندگی، دامنهٔ HTTPS همان پنل. فقط دامنه را وارد کنید؛ مسیر API را خود افزونه اضافه می‌کند.

| روش ارسال | مجوز کلید API | تنظیم لازم |
| --- | --- | --- |
| الگوی رمز پیامکی استاندارد | `sms_otp:send` | شناسهٔ قالب خالی؛ نام سایت و دامنه از وردپرس خوانده می‌شوند |
| الگوی پیامکی اختصاصی | `sms_otp:send` | شناسهٔ قالب تأییدشدهٔ خودتان؛ متغیر کد در آوا `{code}` است |
| رمز صوتی | `otp:send` | شماره و کد؛ قالب، خط یا فایل صوتی در افزونه لازم نیست |
| پیامک متنی | `sms:send` | متن پیام دیجیتس؛ خط فرستندهٔ مجاز اختیاری |

برای حساب فعالِ دارای مجوز سرویس و اعتبار کافی، **OTP استاندارد پیامکی و صوتی به تأیید هر کد یا قالب سیستمی نیاز ندارد و به ساعت کاری تأیید محتوا وابسته نیست**. برای پیامک استاندارد، روش الگو را انتخاب و شناسهٔ قالب را خالی بگذارید؛ برای تماس، روش رمز صوتی را انتخاب کنید. فاصلهٔ ارسال مجدد، محدودیت نرخ، انقضا و سقف حساب اعمال می‌شوند. تأیید قالب‌های اختصاصی و مقررات ارسال متنی جداگانه حفظ می‌شوند.

دیجیتس ۸٫۶٫۲ کد اصلی را جدا از متن به درگاه می‌دهد. در حالت الگو و صوتی، همان کد ۴ تا ۸ رقمی ارسال می‌شود؛ متن کامل پیامک را آوا و صدای کد را سرویس صوتی می‌سازد. در حالت متنی، از متغیرهای دیجیتس مانند `{OTP}`، `{NAME}` و `{DOMAIN}` در متن استفاده کنید. نسخه‌های قدیمی فاقد ورودی کد جداگانه، در حالت الگو به متن دقیق `{OTP}` نیاز دارند.

برای روش الگوی اختصاصی، برند اختیاری باید با برند تأییدشدهٔ قالب یکسان باشد. برای الگوی آماده، برند و متن دلخواه به API فرستاده نمی‌شوند. خط فرستندهٔ پیامک الگویی از قالب آوا تعیین می‌شود؛ فیلد خط افزونه مربوط به روش متنی است.

## نصب فقط اتصال آوا

اگر Digits از قبل نصب است، **ava-Digits-plugin-1.2.0.zip** را نصب کنید. تنظیمات آوا داخل همان صفحهٔ درگاه دیجیتس در دسترس است. صفحهٔ مستقل **تنظیمات ← آوا برای دیجیتس** نیز همان تنظیمات مشترک را ویرایش می‌کند:

```text
/wp-admin/options-general.php?page=ava-digits
```

تنظیمات و کلید نسخهٔ ۱٫۰٫۰ حفظ می‌شوند و روش پیش‌فرض همان الگوی پیامکی است. اتصال تازه به طور پیش‌فرض خاموش است. در بستهٔ مدیانا، callback درگاه اصلی بدون بررسی شناسه عمل می‌کرد؛ اتصال آوا آن callback مشخص را به شناسهٔ IPPanel محدود می‌کند تا درخواست آوا به سرویس دیگری ارسال نشود. در بستهٔ کامل آوا، همان درگاه قبلی اصلاً بارگذاری نمی‌شود.

## کلید و نتیجهٔ ارسال

کلید ذخیره‌شده در HTML بازنمایی نمی‌شود؛ فیلد خالی آن را نگه می‌دارد. برای حذف، گزینهٔ حذف کلید را انتخاب کنید. امکان تعریف در `wp-config.php` نیز وجود دارد:

```php
define( 'AVA_DIGITS_API_KEY', 'YOUR_AVA_API_KEY' );
```

آزمون ارسال در دیجیتس پیامک یا تماس واقعی و هزینه‌دار ایجاد می‌کند. پس از ذخیرهٔ تنظیمات، یک ارسال آزمایشی انجام دهید و نتیجهٔ آن را در **[پنل آوا ← رمز یک‌بارمصرف](https://ava.tarpardaz.com/panel#otp)** بررسی کنید. تست‌های خودکار این مخزن همهٔ ارتباط‌ها را شبیه‌سازی می‌کنند.

پاسخ پذیرش API به معنی تحویل پیامک یا پاسخ‌دادن به تماس نیست؛ گزارش نهایی را در پنل آوا ببینید. نتیجهٔ نامشخص خودکار تکرار نمی‌شود. درخواست یکسان در یک اجرای PHP دوباره فرستاده نمی‌شود؛ انتخاب آگاهانهٔ «ارسال مجدد» در دیجیتس درخواست و هزینهٔ تازه ایجاد می‌کند.

نسخهٔ ۱٫۲٫۰، خطاهای شناخته‌شدهٔ حساب غیرفعال، نبود مجوز کلید، کمبود اعتبار و آماده‌نبودن سرویس را جداگانه توضیح می‌دهد. متن خام پاسخ سرویس نمایش داده نمی‌شود؛ خطای قدیمی یا ناشناخته با پیام عمومی امن نشان داده می‌شود. خطای شبکه یا نتیجهٔ نامشخص را نشانهٔ قطعی ارسال‌نشدن ندانید.

### رد دامنه یا لینک توسط اپراتور

آرینتل ممکن است دامنهٔ داخل متن استاندارد را لینک تشخیص دهد و پیام را با خطای `MessageContainsLink` رد کند. در این وضعیت، سرویس‌دهنده باید مجوز ارسال دامنه/لینک روی حساب و خط آرینتل را بررسی و فعال کند. برای استفاده از مسیر OTP خود آرینتل، دسترسی `OtpAccess` نیز باید از طرف همان سرویس‌دهنده فعال باشد؛ این دسترسی با مجوزهای کلید API آوا مثل `sms_otp:send` و `otp:send` متفاوت است.

**پذیرش API آوا، پذیرش اپراتور یا تحویل پیامک نیست.** وضعیت نهایی را در گزارش آوا بررسی کنید. نصب مجدد یا تعویض افزونه، مجوز حساب یا خط اپراتور را فعال نمی‌کند؛ برای این نوع رد، ابتدا مجوز سمت سرویس‌دهنده پیگیری شود.

## بررسی دستی دریافت و کیفیت صدا

در **۲۰۲۶-۱۱-۰۷**، ارسال واقعی OTP پیامکی و صوتی از پنل آوا و یک نصب آزمایشی وردپرس به‌صورت دستی بررسی شد. در این بررسی، دریافت کد صحیح و حفظ صفر ابتدایی تأیید شد و کیفیت صدای فارسی جدید پس از شنیدن، مورد تأیید انسانی قرار گرفت. این پذیرش، نتیجهٔ همان آزمون است؛ زمان تحویل پیامک یا برقراری تماس را تضمین نمی‌کند.

این پذیرش مربوط به نسخهٔ ۱٫۱٫۱ است. در ۱٫۲٫۰، ساخت اطلاعات سایت و پذیرش درخواستِ شامل متادیتا توسط API آوا بررسی شده‌اند؛ آزمون متن جدیدِ حاوی دامنه با رد اپراتور روبه‌رو شد و تحویل موفق این متن به گوشی هنوز تأیید نشده است. نتیجهٔ دستی قبلی را آزمون تحویل متن جدید تلقی نکنید.

«فوری» در این راهنما یعنی OTP استاندارد به صف تأیید محتوا وارد نمی‌شود. زمان دریافت به شبکه، اپراتور و پاسخ‌دادن مخاطب بستگی دارد.

## داده و حریم خصوصی

برای ارسال، شماره و کد یا متن پیام، شناسهٔ قالب/خط در صورت استفاده و کلید احراز هویت به پنل HTTPS انتخاب‌شده فرستاده می‌شود. در پیامک استانداردِ بدون شناسهٔ قالب، نام عمومی سایت و دامنه نیز با فیلدهای `site_name` و `site_domain` فرستاده می‌شوند؛ این دو فیلد به قالب اختصاصی، پیامک متنی و صوتی اضافه نمی‌شوند. این اتصال گزارش محلی کد نمی‌سازد. در حالت الگوی پیامکی و صوتی، متن گزارش درخواست بومی Digits 8.6.2 با `[Ava OTP]` پوشیده می‌شود. در حالت متنی، خود Digits می‌تواند متن کامل پیامک را در گزارش بومی نگه دارد؛ دسترسی و نگهداری آن را طبق سیاست سایت مدیریت کنید.

فیلدهای اتصال از جمع‌آوری آمار تنظیمات بومی Digits کنار گذاشته می‌شوند. اسکریپت‌های ضروری بستهٔ کامل و فونت جایگزین محلی هستند و برای تنظیمات آوا به CDN عمومی وابسته نیستند.

## توسعه، آزمون و انتشار

نیازمندی اتصال: PHP 7.4+، WordPress 6.5+ و دسترسی HTTPS به آوا.

```sh
php tests/run.php
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 scripts/package.py --tag v1.2.0
python3 scripts/package_full.py --tag v1.2.0
```

بستهٔ کامل از [ZIP مرجع مشخص‌شده](https://cdn.ippanel.com/ippanel/plugin/digits-8.6.2-ippanel-minimize.zip) با SHA256 برابر `457eae74c107750425b8eace1886fe4bbab16e7b0282ba760d32e90f9c13b9aa` ساخته می‌شود. تغییر SHA256 فایل مرجع ساخت را متوقف می‌کند. در خطای شبکهٔ CDN، همان فایلِ ثابت از آینهٔ آوا دریافت و دوباره با همین SHA256 کنترل می‌شود. برای ساخت با نسخهٔ محلی از `--base-zip /absolute/path.zip` استفاده کنید.

خروجی‌ها همراه SHA256 در `build/` قرار می‌گیرند. CI روی PHP 7.4، 8.2 و 8.4 اجرا می‌شود؛ گردش انتشار هر دو ZIP را به Releases اضافه می‌کند. [شرح محیط و آزمون‌ها](tests/README.md).

## English

Ava for Digits provides native gateway settings, standard SMS OTP, approved custom SMS patterns, voice OTP and plain-text SMS. Version 1.2.0 adds the public WordPress site name and home URL hostname to standard SMS requests with a blank template ID; Ava renders the fixed three-line site/domain/code message. Other modes retain their payloads. The full ZIP includes the supplied Digits 8.6.2 distribution with its provider adapter replaced by Ava; the smaller ZIP is an adapter for existing Digits sites. The improved Persian voice runs centrally and also works with 1.1.1 without reinstalling. Eligible, funded accounts can use standard OTP around the clock without per-code or system-template approval; resend intervals, rate limits and expiry still apply. Raw OTP preserves leading zeros. Known machine error codes receive safe explanations; upstream text is never displayed. Uncertain sends are not retried automatically. Read the [Persian setup guide](docs/SETUP-FA.md) and separate third-party notices before selecting a package.
